# Sara's website

A personal site for science, cooking, farming, painting, photography and hiking.
Built with Jekyll (hosted free on GitHub Pages) and edited with Pages CMS.

See **SETUP-GUIDE.md** for how to put it online and how to update it.

Where things live:
- `_data/site.yml`: name, bio, links, section titles
- `_data/publications.yml`: papers
- `_research/`, `_recipes/`, `_farm/`, `_art/`, `_trails/`: one file per item
- `assets/uploads/`: photos you upload
- `assets/css/style.css`: colors and fonts (the color tokens are at the very top)
